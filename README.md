# iPhone 18 Pro Fold — conceito acadêmico

Landing page conceitual para um possível iPhone dobrável, criada como exercício acadêmico de direção de arte, interface responsiva e microinterações.

> Este não é um produto oficial. Nome, características e imagens fazem parte de um conceito visual.

## Estrutura

```text
.
├── index.html
├── css/style.css
├── js/main.js
├── imagens/
│   ├── iphone.webp
│   ├── iphoneAberto.webp
│   └── tresIphone.webp
└── README.md
```

## Recursos

- Layout responsivo para desktop, tablet e smartphone.
- Menu mobile acessível.
- Hero animado com produto em destaque.
- Animações de entrada com `IntersectionObserver`.
- Galeria com lightbox nativa.
- Formulário demonstrativo com confirmação visual.
- HTML, CSS e JavaScript em arquivos separados.
- Suporte a `prefers-reduced-motion`.

## Execução local

```bash
python3 -m http.server 8000
```

Acesse `http://localhost:8000` no navegador.

## Observação

As imagens e o conteúdo são materiais de um conceito acadêmico e devem ser usados respeitando os direitos autorais aplicáveis.
